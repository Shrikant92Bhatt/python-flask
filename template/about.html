Jinja2 Template Inheritance Architecture {% raw %}{% extends "base.html" %}{% endraw %}

How Template Inheritance works in this application:

  1. 1. Parent Skeleton (base.html): Defines the master HTML boilerplate, fonts, CSS links, global navbar, and footer. It reserves placeholders using {% raw %}{% block content %}{% endblock %}{% endraw %} and {% raw %}{% block title %}{% endblock %}{% endraw %}.
  2. 2. Child Template (about.html): Begins with {% raw %}{% extends "base.html" %}{% endraw %} at line 1. It does not repeat the navbar or footer—it only injects its unique page content into the defined blocks.
  3. 3. Key Advantage: Zero code duplication (DRY principle). If you modify the brand logo, navbar links, or footer in base.html, all pages (Home, About, Services, Contact) update instantly!
