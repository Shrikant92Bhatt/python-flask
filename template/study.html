01 Flask Application Setup & WSGI Server
main.py ▾

Concept: Flask initializes an application object that acts as the central WSGI application. Setting template_folder customizes the Jinja templates directory, and app.secret_key enables secure session cookies required for flash messages.

main.py 
from flask import Flask, render_template, request

# Create application instance with custom template folder
app = Flask(__name__, template_folder="template")
app.secret_key = "flaskcraft-dev-secret-key-2026"

if __name__ == "__main__":
    # debug=True enables live auto-reloading and browser debugger
    app.run(debug=True)

03 HTTP Methods Handling (GET & POST)
main.py & contact.html ▾

Concept: By default, routes only accept GET. Adding methods=["GET", "POST"] allows a single route to both render a form and process its incoming submission.

main.py (Contact route) 
@app.route("/contact", methods=["GET", "POST"])
def contact():
    if request.method == "POST":
        # Process form submission
        name = request.form.get("name")
        return render_template("contact.html", success=True, name=name)
    
    # Handle normal page visit
    return render_template("contact.html")
📍 Implemented in: main.py and template/contact.html
04 URL Query Parameters (request.args.get)
main.py & service.html ▾

Concept: Query parameters are appended to the URL after a ? (e.g. /service?tier=pro&promo=FLASK20). Flask parses them into the request.args dictionary. Use request.args.get(key, default) to safely read them with default fallbacks.

main.py (Service route) 
@app.route("/service")
def service():
    # Read query parameters with fallbacks
    selected_tier = request.args.get("tier", default="all")
    discount_code = request.args.get("promo", default="FLASK20").strip()
    
    return render_template(
        "service.html",
        selected_tier=selected_tier,
        discount_code=discount_code
    )
📍 Implemented in: main.py and template/service.html

10 Static Assets Management (url_for vs Direct Path)

Concept: Static assets (CSS, JS, images, SVG) are stored in the static/ directory. They can be linked using Flask's dynamic resolver url_for('static', filename='...') or via direct URLs like /static/....

11 Dynamic URL Generation with url_for()
navbar.html & service.html ▾

Concept: Always use url_for('endpoint_name') instead of hardcoding raw URLs. Any extra keyword arguments are automatically serialized into query parameters.

url_for Examples
{% raw %} 
<!-- Basic route URL: -->
<a href="{{ url_for('home') }}">Home</a>

<!-- Route with Query Parameters: -->
<a href="{{ url_for('service', tier='pro', promo='FLASK20') }}">Pro Plan</a>
<!-- Produces: /service?tier=pro&promo=FLASK20 -->

<!-- Blueprint Route URL: -->
<a href="{{ url_for('flash_demo.flash_page') }}">Flash Demo</a>
{% endraw %}

12 Modular Architecture with Flask Blueprints

13 REST APIs & JSON Responses with jsonify
api.py ▾

Concept: Flask's jsonify() serializes Python dictionaries/lists into JSON strings, sets the Content-Type: application/json header, and pairs with appropriate HTTP status codes (200, 201, 400, 404). Use request.get_json() to parse incoming JSON bodies.

api.py (Endpoints & Responses) 
from flask import Blueprint, jsonify, request

api_bp = Blueprint("api", __name__, url_prefix="/api")

# 1. GET returning JSON data
@api_bp.route("/services", methods=["GET"])
def get_services():
    return jsonify({"success": True, "count": 3, "data": [...]}), 200

# 2. POST accepting JSON body
@api_bp.route("/inquiries", methods=["POST"])
def create_inquiry():
    data = request.get_json()
    if not data or "name" not in data:
        return jsonify({"success": False, "error": "Invalid JSON"}), 400
    return jsonify({"success": True, "data": data}), 201
